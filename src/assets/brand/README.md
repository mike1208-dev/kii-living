# ブランドロゴ（原本）

Illustrator で入稿された PDF を SVG 化したもの。`public/` に置くと参照が
なくても配信されてしまうため、ここに置いている（docs/ は .gitignore 対象のため使えない）。

| ファイル | 用途 |
| --- | --- |
| `logo-mark.svg` | マークのみ。`public/favicon.svg` はこれに余白を足したもの |
| `logo-vertical.svg` | 縦組みロゴ。`public/ogp.png` の生成元 |

サイトで使う横組みロゴは `public/logo.svg`。

ロゴのレッドは `#ff483e`、サイトの `--accent` は `#FF3C34` で厳密には別色。
